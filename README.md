# Doğa ile Dönüş: Su ve Karbon Ayak İzi

Gençler için, soruları tek tek soran su ve karbon ayak izi hesaplayıcısı. Evde, yurtta ya da öğrenci evinde kalanlar için ayrı sorular sorar; faturalar TL ya da miktar olarak girilebilir.

## Yayın

Tek dosyalık statik bir sayfadır (`index.html`). GitHub Pages ile yayınlamak için: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

## Fiyatları güncellemek

`index.html` içindeki `const DATA = { ... }` bloğunu düzenle. Fiyatlar, emisyon katsayıları, tahmini değerler ve kaynaklar bu tek blokta durur.
